# Итоговая работа — Flask Notes App

Веб-приложение на Flask с регистрацией, авторизацией и личными заметками.

## Требования задания

- Flask
- шаблоны Jinja2
- база данных SQLite
- регистрация пользователей
- хеширование паролей
- проверка существующих пользователей
- авторизация
- личный кабинет и работа с заметками

## Как запустить

1. Установить Python 3.
2. Скачать или клонировать репозиторий.
3. Открыть терминал в папке проекта.
4. Создать виртуальное окружение (необязательно, но рекомендуется):

   Windows:
   `python -m venv venv`
   `venv\Scripts\activate`

5. Установить зависимости:

   `pip install -r requirements.txt`

6. Запустить приложение:

   `python app.py`

7. Открыть в браузере:

   `http://127.0.0.1:5000`

База данных `app.db` создаётся автоматически при первом запуске.
